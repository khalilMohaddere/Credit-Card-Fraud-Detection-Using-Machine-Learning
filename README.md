# Credit-Card-Fraud-Detection-Using-Machine-Learning
A Credit Card Fraud Detection project using a Kaggle dataset and machine learning techniques(Logistique Regression,Random forest,XG boost)to identify fraudulent transactions. It involves data preprocessing, exploratory data analysis, feature engineering, handling imbalanced data, and training classification models to detect suspicious activities and evaluate model.
